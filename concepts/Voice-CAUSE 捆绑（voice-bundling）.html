Voice-CAUSE 捆绑（voice-bundling）

概 概念跨时代概念草稿生成语法（最简方案/论元结构句法）2026-09-03

Voice-CAUSE 捆绑（voice-bundling）

定义

Pylkkänen（2008）提出的论元结构参数：外部论元引介层 Voice（Kratzer 1996：施事/外论元）与事件层 CAUSE（致事子事件）在有的语言中捆绑为一个功能头（英语等），在另一些语言中分离为两个头（日语等）。配套参数为使役选择参数（causative selection）：使役语素可选择的补足语大小（词根 root / 动词短语 VP / 含外论元的小句 vP）。两参数共同刻画「词汇使役 vs 形态/分析型使役」的跨语言差异：英语零使役 = 捆绑 + root/VP 选择（只能使役状态变化动词）；日语 -sase = 分离 + vP 选择（可使役非作格/及物动词）。

理论来源

  • Pylkkänen 2002（MIT 博士论文）/ 2008 Introducing Arguments（MIT Press, LIM 49）——voice-bundling 与 causative selection 两参数（Introducing arguments（Pylkkänen 2008））
  • 上承：Kratzer 1996 VoiceP、Chomsky 1995 vP 之争——「外论元/事件由谁引介」的功能头拆分方案之一
  • 下启：Alexiadou, Anagnostopoulou & Schäfer 2006/2015《外论元分层》——将「捆绑 vs 分离」进一步发展为跨语言普遍双头分层（VoiceP × vCAUSE 恒分离；语言差异在 Voice 层的拼出：零拼出 / Voice[−agent] 显性拼出），并以此刻画作格交替、非主动形态多功能（外论元分层（layering approach））
  • 平行方案：Bowers 2000 PrP（谓语短语（PrP））——同一「主语/事件从何而来」争论的另一种功能头切分

核心要点

  • 捆绑语言（英语型）：Voice 与 CAUSE 合一 → 使役结构必然与「外论元引介层」捆绑出现；零使役（kill/break/open）只能选 root/VP 级小补足语 → 词汇使役限于状态变化/结果类动词；非作格（laugh）不可词汇使役（*I laughed John）
  • 分离语言（日语型）：Voice 与 CAUSE 各为独立头 → 使役语素 -sase = 显性 CAUSE 头，可选择 vP 级大补足语（含施事/外论元）→ 非作格/及物动词皆可使役（John-ga Bill-o waraw-ase-ta）
  • 词根语义门槛（与 Harley 2005 同构）：root 级使役要求补足语是「结果状态」类语义（结果根），方式根（laugh 类活动义）过不了选择门槛 → 词汇使役的不可产性获得词根类型学解释（结果根（result root）、方式根（manner root）、零范畴词根（a-categorial root））
  • 理论谱系定位：Pylkkänen 两参数 = AAS 2015 分层理论的直接前身；「捆绑 vs 分离」在 AAS 中被「普遍分离 + 拼出参数」取代（两代理论的差异点与 AAS 对 Pylkkänen 的具体修正待核）
  • 与语法化接口：显性使役语素（-sase 类）与零使役的关系 = 同一功能层（CAUSE）的形态显隐；独立词使役（英语 make/cause、汉语使/令/让）= 分析型拼出——使役层「词缀 ↔ 独立词 ↔ 零形式」的形态光谱 = 句法分析性/分析化与形态化在论元结构层的实例

历时演变示例（汉语史）

  • 上古汉语词汇使动（「活之」「饮之」「破之」）= root/VP 级零使役（结果根并入 vCAUSE，零形态拼出；结果根（result root）、Harley 2005 视角）
  • 兼语使令式「使/令/让 + 小句」（上古已有「使……」，唐宋后「叫/教」加入）= vP 级大补足语的分析型显性拼出
  • 可检验假说：上古使动 → 中古动结式（V2 结果谓词化）→ 使令/把字句的历时序列 = 「使役选择参数（root/VP → vP）+ 拼出方式（零 → 显性独立词）」的协同漂移——与英语词汇使役萎缩（向 make/cause 分析型转移）、罗曼语 faire-使役对照（述补结构、分析化与形态化、句法分析性）
  • 汉语是否 voice-bundling 语言待判：若「把」= 受事引介/致事层、「被」= Voice[−agent] 层、以独立词分别拼出（08-22 AAS 视角），汉语倾向「非捆绑 + 分析性拼出」型——但需独立诊断（判别方法待设计）

争议与问题

  • 捆绑与分离是真正的参数（语言内一致）还是功能头的形态可选项（Pylkkänen vs AAS 的修正式分歧）
  • 「零使役」与「作格交替致使端」是否同一 CAUSE 头（自动端 = 有 CAUSE 无 Voice 的处理在两代理论中不同，细节待核）
  • 汉语使令式（使/令/让）与把字句的致使解读——两者是否共享同一个 CAUSE 层（把书卖了 ≠ 使书卖？语义差别在何处）
  • 上古「饮之」类使动消失的动因：词根使役在动结式兴起后的功能替代，还是语音/形态磨损（需与 分析化与形态化 的宏观叙事衔接）
