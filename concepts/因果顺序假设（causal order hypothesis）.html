因果顺序假设（causal order hypothesis）

概 概念跨时代概念草稿功能语法（认知语言学：力动态 × 框架语义学；与生成语法对照）2026-09-09

因果顺序假设（causal order hypothesis）

定义

论元实现的跨语言普遍性假设（Croft 1991/1998/2012）：语法关系沿因果链顺序映射——在动词侧显的因果链段中，主语 = 段起点（initiator）、宾语 = 段终点（endpoint），不存在因果顺序的逆转；旁语按其在链上相对宾语的位置分为前位旁语（A.OBL，如工具：在宾语之前）与后位旁语（S.OBL，如受益者：在宾语之后）；并入论元位于主语与宾语之间。形式化为四条实现规则（Croft 2012, pp. 206–207）：(a) 动词侧显段以主语与（如有）宾语为界；(b) SBJ → OBJ；(c) A.OBL → OBJ → S.OBL；(d) SBJ → INCORP → OBJ。规则不引用语义角色——角色（施事/致事/工具/受事…）溶解为链上位置 + 百科知识。

理论来源

  • Croft（1991 Syntactic Categories and Grammatical Relations）——假设的成型表述：「在论元实现中没有因果顺序的逆转」（no reversal of causal order in argument realization）
  • Croft（1998 "Event structure in argument linking"）——事件结构向论元链接的映射细化
  • Croft（2012 Verbs: Aspect and Causal Structure）（2026-09-09 精读）——Ch. 5（pp. 173–219）力动态论元实现理论 + 四条规则（pp. 206–207）；Ch. 6（pp. 220–282）跨语言证据（语态、作格性、使役、应用语素）；侧显/框架概念见 侧显（profiling）、链结构见 因果链（causal chain）
  • 平行的功能派表述：Kouhestani et al.（2016）「施事因生命度突显 → 主语前置」的认知类型学（主语突显（subject salience））；Li（1993）子事件象似性（Vcause 先于 Vresult，中心语决定体貌）——三条「顺序原则」分处不同抽象层（参与者注意层 / 链段因果层 / 子事件时间层）
  • 对照的生成派表述：主语 = [Spec, VoiceP/vP] 外论元引介（AAS 2015 分层；外论元分层（layering approach））；宾语 = 内论元/补足语——「发起者居前、终点居后」在两框架中都是结构事实，但解释方向相反（功能：链序 → 语法关系；生成：功能层合并 → 链序副现象）

核心要点

  • 主语 = 侧显段起点、宾语 = 侧显段终点：所谓「主语选择」= 说话人决定侧显哪一段因果链——侧显段加宽/收窄改变论元实现（open 全链侧显 = 致使句带主语+宾语；终点段侧显 = 自动句单论元）
  • 链序 ≠ 表层语序：规则约束的是「语法关系—链位置」的对应（主/宾语身份），不是表层线性位置（处置式「把 NP V」中 NP 仍为终点段、只是被显性标记并线性前移——链序不变；该解读为库内延伸，待核）
  • 旁语的前/后位之分：工具 = 前位旁语（作用于宾语前）、受益/损惠 = 后位旁语（宾语事件之后「作用于」受益者：Sue broke the coconut for Greg ⇢ Greg）——把双宾/与格/受益结构的语序分布（与格交替（dative alternation）、双宾结构（double object construction）、低应用语素（low applicative）、高应用语素（high applicative））纳入同一链序图式
  • 无角色清单：Agent/Patient/Causer 等 = 链位 × 百科特征（意志性/控制力/受影响性）的复合——与 致事（causer） 卡（角色连续统论）互证；与 Heidinger & Huyghe 2024「致事少作主语」的频率发现互译（非意志发起段进入主语位的规约度低）
  • 象似性地位：假设 = 「语法关系映照因果链关系」的图式象似（Haiman 动机象似；象似性（iconicity））——因果顺序是语序/语法关系象似性的最强候选普遍性之一

历时演变示例（汉语史）

  • 动结式：「打破/救活」V1（因/方式段）→ V2（果/变化段）的线性 = 因果链序的句法化（与 Li 1993 子事件象似同域互证；述补结构）
  • 把字句：把 NP V = 终点段（受事）显性标记 + 线性前移——处置式的产生可重述为「终点段显性化构式」的兴起；与「以/将/把」工具-处置介词竞争（工具 = A.OBL 前位旁语、受事 = OBJ 终点段，两类论元的标记策略竞争）相关（持拿义动词语法化、把字句的来源研究综述；库内延伸，待核）
  • 被动句：「被 NP V」= 侧显段含终点段但发起段不占据主语位（去发起者化的构式化）——处置/被动的同现句「被他打破了」= 同一条链上终点段（把后 NP）与旁语化发起段（被后 NP）的共现（被动句、处置式与被动式演变的参数互动；库内延伸，待核）
  • 受事主语句/话题化：受事话题居首（这本书我看完了）在链序规则下 = 终点段被话题化（非主语化）——汉语话题优先的链序解释方向（话题化、广义控制理论；待核）

争议与问题

  • 心理动词的挑战：frighten 类（吓/气/烦）主语 = 刺激/致事（非意志发起者）、宾语 = 体验者——「发起者」无意志时是否仍算链起点？体验者受影响段是否 = 终点段？（Croft 2012 Ch. 6 以「非典型因果关系（心理事件）」专节处理，细节待核；心理动词（psych verbs）、体验者（experiencer））
  • 无分支约束 vs 共享论元：动结式「追累」类（V1 与 V2 共享主语/宾语）与双及物结构在无分支链上的表征（链合并/分支的认知解法）——与生成派 VP-shell/补足语小句分析的可译性（谓语短语（PrP））
  • 可证伪性/操作化：历史语料上标注「链段」比标注「语义角色」更可行还是更不可行？（把字句主语历时分布 = 施事→致事扩展（Heidinger 接口）可作两套标注系统的判别场）
  • 线性语序偏离：OV 语言/宾语前置（把字句、上古代词宾语前置 代词宾语前置（上古汉语））在「链序 → 语法关系」规则下如何获得线性解释——链序规则若只管语法关系，则它对语序演变（语序演变）的解释力边界何在？
