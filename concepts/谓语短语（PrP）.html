谓语短语（PrP）

概 概念跨时代概念草稿生成语法2026-08-21

谓语短语（PrP）

定义

Bowers（1993/2000）提出的功能投射：所有谓语（VP/AP/NP/PP）都必须由功能中心语 Pr（Predication head，谓语中心语）引介主语。小句最小结构为 [TP [PrP 主语 [Pr' Pr [谓语 XP]]]]：主语在 [Spec, PrP] 获得「被断言对象」身份（谓词饱和），后因 EPP 移至 [Spec, TP]；Pr 的补语是任意谓语性短语，Pr 承担「主语-谓语」关系的句法化——谓语性（predication）不再是理论设定，而是拥有独立句法位置的运算。

理论来源

  • Bowers 1993 "The syntax of predication"（Linguistic Inquiry 24: 591–656，出处待核）——PrP 初始论证
  • Bowers 2000 "Predication"（The Handbook of Contemporary Syntactic Theory, 299–333）——系统化综述（已精读 2026-08-21，Predication（Bowers 2000））
  • Bowers 2002 "Transitivity"（Linguistic Inquiry 33.2: 183–224）——Pr 分裂为 Pr + Tr（Tr 引介直接宾语并赋宾格）
  • 平行方案：Kratzer 1996 VoiceP（外论元引介）、Chomsky 1995 轻动词 vP——1990 年代「外论元/主语句法化」浪潮的三条路线
  • AAS 2015 外论元分层（2026-08-22 补）：另一条「分裂」路线——Voice（引介外论元、施事性）× vCAUSE（引介致事子事件）双头分层；Pr 的功能（引介主语）≈ Voice 的功能（引介外论元），Tr 的功能（引介直接宾语）≈ vCAUSE/及物性层——Pr/Tr 分裂与 Voice/vCAUSE 分层是同一争论的两种切分，对作格交替/被动/中动的刻画各有取舍（外论元分层（layering approach）、External arguments in transitivity alternations（Alexiadou, Anagnostopoulou &amp; Schäfer 2015））
  • 汉语应用：Sybesma 1999 The Mandarin VP（Kluwer）——把字句「把」= Pr 的语音实现；AAS 框架下「把」亦可分析为 vCAUSE/Voice 层分析性拼出（两种切分的判别是开放问题）

核心要点

  • Pr 是纯功能中心语：其补语类型不限（VP/AP/NP/PP），不随词类变化；Pr 的 [+N]/[+V] 特征组合决定允准的补语类型（如 POSS-ing 动名词，细节待核）
  • 主语两步走：[Spec, PrP]（θ/谓语性位置）→ [Spec, TP]（EPP/格位置）；浮游量词（the students all left 中 all 留在 [Spec, PrP]）与副词分布（Pr' 附加）可作 PrP 边界诊断（细节待核）
  • 统一解释力：非宾格宾语移位（the ship sank）、小句/ECM/使役补语（believe John honest、make John leave）、双宾句（give Mary a book，Mary 为内嵌 PrP 主语）、系词 be（Pr 的语音拼出）均由 PrP 统一
  • 与 vP/Voice 的关系：Pr 与 v/Voice 是同一功能层（外论元/主语引介层）的竞争实现；Bowers 2002 的 Tr 层与 Chomsky 的 vP 在「及物性」分工上各有取舍——该层是否分裂、如何分裂是后续争论
  • 历时句法意义：Pr/v 层是功能语类（功能语类）语法化的目标层之一——「把/将」由连动式 V₁ 虚化为处置介词，在生成框架内可重述为「词汇动词 → Pr 中心语」的向上重分析（句法重铸（syntactic reformulation）、语法化的生成句法解释）

历时演变示例（汉语史）

  • 「把/将」：持拿义动词 → 连动式 V₁ → 处置介词（唐以后；持拿义动词语法化）——若取 Sybesma 1999，其终点位置即 Pr 中心语（把 + 受事 + 结果/谓语小句）；「把」= 功能语类以独立词拼出（句法分析性），与英语 be（Pr 的语音拼出）平行
  • 动结式「V 得 C / V 死 O」：结果小句可分析为 PrP 补语（述补结构小句分析一侧）；「把 + O + VC」= 把（Pr）+ 谓语小句（VC）结构
  • 作格交替「门开了/开门了」：自动端 = 内论元移至 [Spec, PrP]；致使端 = Tr/vCAUS 层（零拼出或不投射，作格交替（causative-anticausative alternation））

争议与问题

  • PrP vs vP vs VoiceP：同一功能层的三种实现，其语义-句法分工（主语引介、宾格、施事性）如何判定？AAS 双头分层（Voice×vCAUSE）与 Bowers Pr/Tr 分裂的切分竞争（2026-08-22 补）
  • 「把」= Pr 拼出 vs 介词分析：对处置式历时来源（唐前无真处置式、将先于把，Peyraube 1989）的预测力比较——Pr 分析须回答「为什么 8 世纪才出现」与「为什么是持拿义动词」
  • 汉语无形态环境下 Pr/v 层的「存在性」证据：与 句法分析性（功能语类可选拼出）的接口；空 Pr 与零拼出是否同一回事
  • Pr 的特征分析（[+N]/[+V]）与动名词/名物化结构（名物化）的关系待核
