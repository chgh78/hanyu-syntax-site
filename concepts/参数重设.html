参数重设

概 概念跨时代概念完善中历时生成句法学2026-08-03

参数重设

定义

语法变化不在成人语法的内部发生，而是发生在代际传递环节：儿童基于输入语料（触发经验，triggering experience）设定参数值，当输入语料的数据结构发生变化时，新一代习得者设定的参数与上一代不同，语法即发生历时变化（Lightfoot 1979, 1991, 1999）。

理论来源

  • Lightfoot 1979 Principles of Diachronic Syntax（剑桥大学出版社）——把生成语法的语言习得观引入历时研究，语法变化 = 参数值的代际改变
  • Lightfoot 1991 How to Set Parameters——触发经验与「退化的输入」（degenerate input）
  • Lightfoot 1999 The Development of Language——习得、变化与演化统一框架；第 1 章「语法生长说」（语法是儿童从 PLD 中生长的器官，变化是习得的副产品），第 3 章线索模型作为历时机制（线索消失 → 参数重设）与「语法化 = 习得性重分析的副产品」说（The Development of Language（Lightfoot 1999），第 1-3 章已精读）
  • Lightfoot 1991 How to Set Parameters——线索（cue）模型：儿童扫描输入中的抽象结构线索，线索须以足够频率/强度出现才能支撑参数设定（线索阈值）
  • Clark & Roberts 1993 "A computational model of language learnability and language change"（Linguistic Inquiry 24）——可学性计算模型：学习者收敛于「与 PLD 相容且最经济」的语法，参数转变伴随双语法过渡期
  • Longobardi 2001——惯性原则（惯性原则）：语法惰性，参数变化须外部触发
  • Roberts 2007 Diachronic Syntax——教材综述（2026-08-06 已按 PDF 原文补全页码）：第 3 章 §3.2 语言变化的逻辑问题（pp. 226-235：逻辑问题 (16) p.230、弱决定论 p.231、惯性原则 (17)(18) pp. 231-232、P-表达/触发 (20) p.232、P-歧义 (21) pp. 232-233、复杂性 (22) p.235）；§3.3 变化的触发（pp. 236-251：接触驱动/线索驱动/形态驱动三路径）；§3.4-3.5 标记性与参数设定（pp. 251-282：参数格式 (52) p.267、Borer–Chomsky 猜想转述 §4.1.3 p.299）；§2.5 OV>VO 的反对称分析（pp. 189-197）
  • 与 Kroch（1989）竞争语法互补：参数重设解释「质变」，竞争语法解释「量变」的表层进度

核心要点

  • 变化是非连续的：每个个体语法是离散的参数系统，变化发生在学习者身上；成人语法稳定——成人不改变语法，变化只经代际习得实现（Lightfoot 1999：语法变化是习得的副产品）
  • 触发经验的具体化 = 线索（cue）（Lightfoot 1991/1999）：儿童从主句 PLD 中提取抽象结构线索，线索消失/低于阈值 → 参数重设（详见 线索驱动习得）
  • 表层语料的歧义性（ambiguity）是新分析得以产生的温床 → 与重新分析对接
  • 变化动因在输入语料（频率、语体、语言接触造成的语料结构变化），不在成人语法
  • 是「外因触发、内因实现」框架：语言接触/使用变化 → 输入改变 → 参数重设
  • 线索模型（Lightfoot 1991/1999）：儿童扫描输入中的抽象结构线索（cue，如「非主语成分占据 CP 指定语」= V2 线索）；线索频率低于阈值时旧参数值不再被设定 → 频率变化成为参数重设的触发（衔接频率效应（句法演变））
  • 参数即功能语类特征（鲍勃-乔姆斯基猜想）→ 参数变化 = 功能语类特征改变；宏参数是微参数簇（宏参数与微参数）；第 5 章把语法化（改变功能语类特征）与参数重设统一为「微变 → 宏观」
  • 启动问题与惯性原则（Longobardi 2001）：语法不自发变化，须外部触发（语音侵蚀、接触、分布改变）；「为什么此时此地变化」的答案是「PLD 变了」（惯性原则）
  • 语言变化的逻辑问题（Roberts 2007: 226-235）：(16)「如果一代的触发经验足以让该代设定 pk=vi，为什么该代产生的触发经验不足以让下一代设定 pk=vi？」（p.230，C&R 1994: 12）——统摄 §2.1 的 Regress Problem；解答 = 弱决定论（设参为目标、无需与成人语法收敛，「approximation usually amounts to replication」，p.231）＋ 惯性原则 (17)（Keenan 2002: 2，p.231）＋ Longobardi 版 (18)（「syntactic change should not arise, unless it can be shown to be caused」，p.232）＋ P-表达/触发 (20) 与 P-歧义 (21)（强 = 两种值皆可指派、弱 = 两种值皆不触发）（pp. 232-233）＋ 复杂性 (22)：表征简单 ⇔ 更少形式特征（p.235）
  • 触发的三种路径（§3.3，pp. 236-251）：①接触驱动（PEI 法语介词悬空——借入英语介词 → 参数推广，King 2000，pp. 238-242；直接 vs 间接接触图式 (23) pp. 236-237）；②线索驱动（Dresher 1999 参数三段式：参数 + 默认 + 线索；Lightfoot 1999 线索 [T V] 与三扰动因素，pp. 242-245；线索 ≠ 参数，p.244）；③形态驱动（(34) 一致形态 → V-to-T 的 P-表达；(37) 形态与格 → 抽象与格的单蕴涵；(41) 不定式时体 → 非限定 T 的宾格特征——形态丧失创造强或弱 P-歧义，pp. 245-250）——三条路径不互斥（p.236）
  • VEPS 的张力（§3.1，pp. 209-225）：参数设定极早且准确（两岁左右，p.210-211）与参数历时可变并存——根不定式与早期空主语两现象都不能直接关联参数变化（pp. 214-224），但不证伪习得驱动说（p.224）

历时演变示例（汉语史）

  • 上古汉语宾语前置（否定句、疑问句代词宾语前置）在中古消失，可视为代际间参数设定变化的候选案例（与语序演变关联）
  • 近代汉语处置式「把」从动词到功能语类的演变，若按 Roberts & Roussou（2003）则是功能语类扩展而非参数重设——两类机制如何区分，是汉语史研究的核心问题之一
  • 待补：用参数重设框架重新分析「述补结构产生」（述补结构）

争议与问题

  • 「参数」概念本身受质疑（微参数 microparameter 与 Borer–Chomsky 猜想：参数即词库特征）——宏参数是否真实存在（宏参数与微参数「争议与问题」）
  • 汉语缺乏形态证据，参数变化在汉语史上可观察的「语法指纹」是什么？——线索模型中的「结构线索」在无形态语言中如何定义（待核：Roberts 是否讨论）
  • 与韵律句法学（冯胜利）的驱动机制之争：语序变化是参数性的还是韵律性的？
