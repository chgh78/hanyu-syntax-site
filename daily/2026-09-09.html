今日论文

Verbs：Aspect and Causal Structure（Croft 2012）（队列条目：Verbs: Aspect and Causal Structure（Croft William. · Zotero:专业综述-把字句的来源 2026-05-02）；条目实为 Croft, William. 2012. Verbs: Aspect and Causal Structure. Oxford: Oxford University Press, xvii + 468 pp.，ISBN 978-0-19-924858-2；✅ 书目已在线核实（Crossref 章级 DOI 10.1093/acprof:oso/9780199248582.003.0007/.0008 = 本书第 7/8 章；OpenAlex 书评记录 Depraetere 2015/Kasper 2013/Iwata 2014）；inbox 无 PDF → 据 Depraetere 2015 书评全文精读重构（Linguistics 53(1): 199–207，DOI 10.1515/ling-2014-0030，HAL 开放获取 hal-01187465，逐章含原书页码；原书内部语例/图式待核）

一句话概括

Croft（2012）把「语法化了的事件结构」做成三维单一表征：事件 = 参与者子事件沿力传递方向串成的因果链（第三维）× 各子事件自带的 t/q（时间 × 质态）体貌轮廓——动词在时体构式中侧显体貌相位的连续段、在论元结构构式中侧显因果链的连续段（核心平行论，p. 206）；论元实现因此只剩四条链序规则（主语 = 侧显段起点、宾语 = 终点、前/后位旁语分居两侧，无须语义角色清单）；Vendler 情状类不是动词固有分类而是「体貌潜能 × 构式识解 × 频率默认」的产物（状态 4/达成 3/活动 2/完结 2 细化分类 + q-有界/t-有界两界论），复杂事件整体情状由动词体貌层级（定向变化 > 无定向变化 > 状态，p. 286）最高的子事件决定。为库内生成派诸分析（vCAUSE/Voice 分层、词根类型、中心语继承）提供认知-构式（反生成派）的平行坐标，并为把字句/动结式/作格交替提供「因果链分段与侧显方式的历时重组」这一新的分析语言。

三个要点

  1. 因果链 + 侧显 = 论元实现的认知机制——Croft 力动态因果链（一参与者一子事件；Sue → hammer → coconut ⇢ Greg，实线 = 动词侧显段、虚线 = 旁语侧显段）上，主语 = 动词侧显段的链起点、宾语 = 链终点；四条规则（SBJ → OBJ；A.OBL → OBJ → S.OBL；SBJ → INCORP → OBJ；pp. 206–207）同时覆盖核心论元与旁语、不引用语义角色（角色 = 链位 + 百科特征）——「语义角色溶解」为因果链位置论：施事/致事 = 意志/非意志的发起段、工具 = 中间传递段、受事 = 终点受影响段；与 Heidinger & Huyghe 2024「致事少作主语」频率发现、把字句受事宾语（终点段显性标记）直接互译。
  2. 体貌 = t/q 二维几何 + 识解——词法体「描述事件如何被识解为按质态序列随时间展开」（p. 53）：q-有界（有结果状态/自然终点）与 t-有界（侧显的时间边界）两界分离，消解「有界/终结」混用；Vendler 细化分类（状态 4 小类含点状态、达成 3 小类含无定向循环达成 = 单变、活动 2 小类、完结 2 小类含非增量 runup）；完整体/非完整体 = 定向 vs 无定向轮廓两族识解（pp. 171–172）——给「了/着」对立提供全局语义定义选项；体貌潜能 × 构式（进行体 = 过渡状态化过滤器，p. 155）+ 频率定默认（usage-based，反对派生/强制规则）。
  3. 体貌 × 因果整合（Ch. 7–8）——整体事件情状 = 体貌层级最高子事件（定向变化 > 无定向变化 > 状态，p. 286）：Sally pricked the bread = 定向达成（面包受瞬时定向变化）、Bill tapped the sideboard = 无定向活动（侧板不受影响只「存在」）；结果动词 vs 方式动词（Levin & Rappaport Hovav 2005/Talmy 框架类型）之别 = 有无定向变化段（≈ Harley 2005 结果根/方式根的功能-认知平行）；复杂谓词构式（动结式/连动式/副动词式）表达比简单动词更宽的子事件关系 → 反推简单动词的词汇化约束（无分支/时间统一/单一向变化）——动结式与连动式正是汉语「把/将」虚化与 V2 体标记化的共时构式底座。

知识关联

  • 新建论文（1 篇，已挂 论文索引 理论区，位于 Porwol & Scharlau 2025 之后）：Verbs：Aspect and Causal Structure（Croft 2012）（据 Depraetere 2015 书评逐章重构精读；原书页码以书评为中介；页数 468 待核）
  • 新建概念（3 张，已挂 概念索引 理论概念区，位于走私移位（smuggling）之后）：
  • 因果链（causal chain）——事件结构表征：参与者个体子事件沿力传递的有向链（一参与者一子事件、自带 t/q 轮廓）；简单动词词汇化约束（有向/无环/无分支/时间统一）；语义角色溶解为链位 + 百科知识；生成派 vCAUSE/Voice、词根类型的认知平行坐标
  • 侧显（profiling）——表达从背景框架中侧显部分为义（Langacker profile/base）；Croft 推广：动词侧显体貌相位（时体层）/因果链段（论元结构层）；作格交替 = 同链两侧显；与「突显/salience」相对（语言结构化 vs 注意力属性）
  • 因果顺序假设（causal order hypothesis）——主语 = 侧显链段起点、宾语 = 终点、无因果顺序逆转（四条规则 pp. 206–207）；= 动因象似在论元实现上的强式操作化；与主语突显（线性）、Li 1993 子事件象似构成「顺序象似三层次」
  • 更新概念（4 张）：情状类型（补：t/q 两界论、Vendler 细化分类、体貌层级、识解观第三条路）、作格交替（causative-anticausative alternation）（补：因果链侧显观 + 「侧显 vs Voice 层」判别诊断）、致事（causer）（补：角色溶解 = 因果链发起段 + 无意志百科特征）、象似性（iconicity）（补：因果顺序规则 = 动因象似强式操作化；顺序象似三层次）
  • 更新综述：把字句的来源研究综述（相关论文补本文；相关概念补 3 张新卡；研究空白新增第 8 项「把字句/动结式的因果链侧显分析——链段标注 vs 角色标注判别场」）
  • 更新想法：比较句法学视野下的近代汉语致使结构研究（致使史 = 因果链分段/侧显重组的功能-认知平行表述）、处置式与被动式演变的参数互动（把/被 = 同链两侧显构式化；「被他把书拿走了」同框句 = 同链双标记）
  • 链接到的研究想法：汉语语法化产物与句法分析性——功能语类显现方式的历时证据（「侧显规约化」（认知） vs 「拼出方式漂移」（生成）的历时证据判别；V2 → 体标记 = 段位塌缩的判别场）
  • 候选研究想法（暂不建卡，详见今日思考问题）：① 把字句主语历时分布的「链段标注 vs 角色标注」双系统试标（判别哪套更适合历史语料）；② 动结式 V2 虚化（破→却→了/得）四框架（组合计算/中心语继承/词根类型/侧显段塌缩）预测差异的历时检验；③ 「自发性副词」（自己/自然）+ 自动端 vs 施事副词 + 致使端的分布不对称 = 「侧显说 vs Voice 层说」的汉语判别诊断

今日思考问题

  1. 把字句宾语并非都经历状态变化（把书看了 = 零/低受影响）——Croft「宾语 = 因果链终点（受影响者）」如何容纳？若终点段只需「被作用于」无须 q-变化，处置式与普通及物句的因果链差异何在——把字句是「终点段侧显 + 前移线性化」的双重标记构式吗？（把书看了 vs 看了书：处置式的功能域扩张 = 终点段要求的放宽？衔接 Peyraube 1989 宾语有定条件）
  2. 汉语动结式 V2 虚化链（破/却/将/得 → 了）在四说——组合特征（Olsen）、中心语继承（Li 1993）、词根类型（Harley 2005）、侧显段规约化（Croft 2012）——下各有何预测？「终点定向变化段塌缩为语法体标记」若为真，哪套机制的刻画可操作、可检验（了₁ 的「完成 = 终点段侧显语法化」解读）？
  3. 「侧显 vs 结构」判别诊断：认知说预测自动端（门开了）只是终点段侧显（可经识解容纳自发性副词「门自己开了」），生成说（AAS）预测自动端无 Voice[+agent]（禁施事副词、可容致事附加语）——「自己 + 自动端」「故意 + 致使端」的合法分布与「玻璃自己碎了/自己杀自己（反身）」能否分出两说的经验差异？还是纯粹术语等价？
  4. 「顺序象似三层次」假设（注意层/链序层/子事件层）若成立，处置式（终点段前移、链序不变）与上古代词宾语前置（代词宾语前置（上古汉语））便是「线性偏离链序」的测试域——把字句「把 NP V」的 NP 若仍是链终点，为何要线性前移？受事突显（主语突显（subject salience） 的镜像）与链序规则谁解释线性位次？（衔接 汉语语序演变的参数重设路径）
