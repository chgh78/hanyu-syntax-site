Introducing arguments（Pylkkänen 2008）（队列条目：Introducing arguments（L Pylkkänen · Zotero:专业综述-把字句的来源 2026-05-02）；inbox 无 PDF，据知识精读：queue 条目实为 Pylkkänen, Liina. 2008. Introducing Arguments, Cambridge, MA: MIT Press（Linguistic Inquiry Monograph 49），前身为作者 MIT 博士论文（文献通行引用作 2002 年，有引 2000 者，待核）；⚠️ 书目未在线核实（与既往条目不同，本次无 Crossref 步骤），页数/ISBN/章节结构/页码均待核）

一句话概括

Pylkkänen（2008）系统提出「论元引介功能中心语」理论：附加论元与外论元不由动词词汇属性赋予，而由普遍可用的功能头（高应用 ApplHigh / 低应用 ApplLow / Voice / vCAUSE）在句法中引介；跨语言差异不在中心语有无，而在选择特性（补足语大小 root/VP/vP）与捆绑方式（voice-bundling：英语 Voice 与 CAUSE 合一、日语分离）——「论元结构 = 功能语类参数」的纲领性著作，与 外论元分层（layering approach）（AAS 2015，2026-08-22 精读）、双宾结构（double object construction）（Beck & Johnson 2004，2026-08-24 精读）、Harley 2005 词根论（2026-08-25 精读）同属 Kratzer-Marantz 论元结构谱系，本日为知识库补上该谱系的「源头书」。

三个要点

  1. 应用语素二分（高/低）：ApplLow = VP 内、引介与直宾构成领属/转移关系的论元（英语双宾 give John a book：John 领有 book；bake 双宾必含「得到蛋糕」蕴含）；ApplHigh = vP 与 VP 之间、引介与事件有修饰关系的个体（班图语 Chaga 受益格，受益者无须领有受事；英语无高应用）——两中心语独立、语义有别（个体-个体 vs 个体-事件）。to-与格 = 普通介词补足语（非应用结构）→ 双宾与与格非转换观的第二条独立论证（与 Beck & Johnson 2004 的 again 恢复义论证互证）。
  2. 使役两参数：voice-bundling（英语 Voice+CAUSE 捆绑为一头 vs 日语分离）+ 使役选择参数（使役语素选 root/VP/vP）——英语零使役 = 捆绑 + root/VP 选择 → 只能使役状态变化动词（I laughed John 不可）；日语 -sase = 分离 + vP 选择 → 非作格/及物皆可使役（waraw-ase-ta）。非作格词根（方式根）无结果状态、过不了 root 级选择门槛——与 Harley 2005（2026-08-25）的词根类型学直接同构*。
  3. 理论谱系定位：AAS 2015「外论元分层」（Voice × vCAUSE 恒分离、语言差异在 Voice 层拼出）的直接前身 = 本书的 voice-bundling/选择参数（AAS 把「捆绑 vs 分离」改造为「普遍分离 + 拼出参数」，两代理论差异点待核）；与 Bowers 2000 PrP（2026-08-21）、Sybesma「把 = Pr 拼出」构成「论元/主语引介功能头」三方案对照。

今日思考问题

  1. 汉语是 voice-bundling 语言还是分离语言？若「被/把/使」分别拼出 Voice[−agent]/受事（致事）引介层/使令层（2026-08-22 AAS 视角 + 今日两参数），汉语的「非捆绑」与黄正德 2015 的「分析性参数」（句法分析性）是否同一参数在两个层面的表现——「论元结构层的功能语类独立拼出」？该判别有无可操作诊断（把/被同现、使令句的内嵌施事等）？
  2. 上古「饮之/活之」零使役 → 使令式「使之饮/使活之」的此消彼长，能否用使役选择参数的历时漂移统一刻画（root/VP-selecting 零拼出 → vP-selecting 显性拼出）？漂移动因是词根使役的能产性衰竭（V₂ 动结式吸收结果根）还是信息结构/分析化总趋势？「叫/教」唐宋加入使令系统在参数框架中意味着什么（新语素 = 新选择特征？）？
  3. 低应用语义（双宾必含领属转移蕴含）若适用于上古汉语：给予类（予之粟）、夺取类（夺之牛）与教类（教之射）三类双宾的结构一致性——教/问类无领属蕴含是否说明上古已有「非低应用双宾」，还是「教/问」应分析为别的结构（兼语/连动）？「夺之食」的损惠低应用可否作 ApplLow 两极性（gain/loss）的汉语历时证据？
