今日论文

Double objects again（Beck &amp; Johnson 2004）（队列条目：Double objects again（Beck · Zotero:专业综述-把字句的来源）；inbox 无 PDF，据知识精读；⚠️ queue 条目作者字段仅录「Beck」，实为 Beck, Sigrid & Kyle Johnson 合著——Linguistic Inquiry 35(1): 97–123（2004），书目与摘要已在线核实（Crossref，DOI 10.1162/002438904322793356，被引 119 次）；正文论证细节与页码待核）

一句话概括

Beck & Johnson（2004）用副词 again 的恢复义（restitutive reading）解读作为结构探针：双宾句（give Mary a book）允准「接受者先前拥有主题」的恢复义，证明其补足语是以 HAVE 为核心谓词的领属小句（CAUSE [接受者 HAVE 主题]）；介词宾语句（give a book to Mary）的恢复义随动词而异（give 类 = 领属、send/throw 类 = 处所），证明其不与双宾结构转换相关——为双宾/与格关系的「非转换观」（反 Larson 1988/1990）提供了语义-句法接口证据，也为汉语双宾/与格/把字句共享的「领属-转移」语义域提供了生成语义基础。

三个要点

  1. 恢复义 = 结果状态的解读探针：again 两读（von Stechow 1996）——重复义修饰事件、恢复义修饰/预设结果状态；恢复义可得 ⇔ 结构中有可独立修饰的结果状态成分。「门又开了」可读「门重新开着」（恢复义），正是结果状态存在的信号（恢复义（restitutive reading））。
  2. 双宾 = 领属小句分解：双宾句的恢复义（「Mary 先前拥有书」）要求结果状态 = 领属状态 → DOC = [v CAUSE [SC 接受者 HAVE 主题]]（McCawley 1972「have」分解、Kayne 1993、Harley 1995/2002 的 CAUSE-HAVE 传统）；接受者是 HAVE 小句的主语（HAVE 小句（领属小句）；与 Bowers 2000 PrP 分析竞争，谓语短语（PrP））。
  3. 与格/介词宾语句 = 非转换相关：若 DOC 由 NP+PP 移位派生（Larson 1988），两类结构结果状态应相同；实际 NP+PP 的恢复义随动词而异（give 类领属、throw/send 类处所）→ 与格结构与双宾不互为派生、依动词事件结构而变（与格交替（dative alternation））。

知识关联

  • 新建论文（1 篇，已挂 论文索引 理论区）：Double objects again（Beck &amp; Johnson 2004）——again 恢复义探针 → 双宾 = HAVE 领属小句、与格非转换观；书目已在线核实（Crossref，DOI 10.1162/002438904322793356），正文语例待核
  • 新建概念（4 张，已挂 概念索引）：
  • 双宾结构（double object construction）（结构类型）——两个宾语论元的结构；宾语层级不对称（Barss & Lasnik 1986）；SC-HAVE 分解 vs PrP 分析；汉语史：上古「赐/予」双宾 → 中古「与/给」→ 现代「给他一本书」；「与/给」V₂ 位介词化 = 「把/将」V₁ 位介词化的镜像
  • 与格交替（dative alternation）（理论概念）——双宾 vs 介词宾语句的交替；转换观（Larson 1988/1990）vs 非转换观（Beck & Johnson 2004）；汉语「给」的动词/介词双重身份与历时来源
  • HAVE 小句（领属小句）（理论概念）——以 HAVE 为核心的领属小句；双宾 = CAUSE + HAVE 分解；领属语义域贯穿双宾/把字句（持拿义）/系词「有」；「持有 = 控制」为处置式与双宾共享语义域的认知基础
  • 恢复义（restitutive reading）（理论概念）——again 的重复/恢复两读；恢复义 = 结果状态存在性的解读探针；汉语「再/又/复」恢复义歧义可作近代汉语结构历时诊断
  • 更新概念（3 张）：
  • 谓语短语（PrP）（补竞争路线：双宾的 SC-HAVE 小句分析 vs PrP 分析，恢复义为判别性检验）
  • 持拿义动词语法化（补持拿义与领属义 HAVE 的语义亲缘——「把」V₁ 虚化与「给/与」V₂ 虚化的镜像）
  • 处置式（补领属/持拿语义维度：把字句持有分析（Ziegeler 待读）的生成语义基础 = HAVE 小句）
  • 链接到的研究想法：比较句法学视野下的近代汉语致使结构研究（双宾/与格/处置共享领属语义域）、汉语语法化产物与句法分析性——功能语类显现方式的历时证据（「给/与」的功能语类化）
  • 相关综述：把字句的来源研究综述（本条目所在 Zotero collection——双宾/处置交叉文献，如石毓智「汉语双宾结构与动补结构的构式同化」队列条目）、汉语语法化研究综述（给予动词 → 与格介词的语法化渠道）
  • 候选研究想法（暂不建卡）： 1. 汉语「与格交替」的历时实态——「予之粟」vs「予粟于之」（上古）→「送他一本书」vs「送一本书给他」（现代）：双宾/介词句的语序竞争史；「给/与」的 V₂ 位介词化与「把/将」的 V₁ 位处置介词化构成连动式内两端的镜像语法化（语法化的句法环境 的新案例，衔接 双宾结构（double object construction）、与格交替（dative alternation））。 2. 「恢复义探针」的汉语史迁移——用「再/又/复」的重复/恢复义歧义分布，检验近代汉语动结式、把字句、双宾结构的结果状态成分是否已句法化（方法论迁移自 Beck & Johnson 2004；衔接 恢复义（restitutive reading）、述补结构）。 3. 领属语义域与致使结构的历时重组——「有」字句（上古存在/领属）→ 双宾（接受者领有）→ 把字句（持拿/处置）：「持有 = 控制」概念隐喻（概念隐喻（conceptual metaphor））在句法层的实现（HAVE 小句 → 处置层）；与石毓智「双宾结构与动补结构的构式同化」（队列待读）对接。

今日思考问题

  1. 汉语双宾（「给他一本书」）与介词句（「送一本书给他」）是否构成严格意义的与格交替？「给」的双重身份（V/P）是共时兼类还是历时语法化（给予动词 → 与格介词 → 受益/被动标记）的共时残留——非转换观对汉语「给」字句的适用性如何？
  2. 上古汉语双宾（「赐之金」「予之粟」）的接受者可否分析为 HAVE 小句主语？「赐金于之」类「于」字介词句何时兴起、与双宾如何竞争（竞争语法案例）——「于」是否上古汉语的与格介词？
  3. 把字句「持拿义」与双宾「领属义」共享语义域——处置式与双宾/与格是否同一「领属-转移」语义域的两种句法实现？「持有 = 控制」的认知映射（概念隐喻（conceptual metaphor））与 Peyraube 1989 的连动式句法条件（语法化的句法环境）在此语义域中如何分工？
