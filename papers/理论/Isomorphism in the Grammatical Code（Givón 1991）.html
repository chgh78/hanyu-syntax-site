一句话概括

Givón 论证语法代码大体是同构的（isomorphic）：形式与功能之间存在强烈的「一一对应」（bi-uniqueness：one form ↔ one function）编码压力，共时语法是「大体同构、局部错配」的动态平衡——错配的两个方向（一词多义/同音异义 vs 同义异形）主要是语法化的系统副产品（链的中间态多义、一源多流、多源平行语法化、语音磨损合流），语言又通过更新（renewal）与竞争恢复同构，由此解释语法化的循环性与方向性。这把「形式-功能错配」从例外现象重述为可预测的历时规律——共时错配是「进行中的语法化」的化石，可用来重建语法化路径。

核心问题

  1. 语法代码是任意（arbitrary）的还是非任意/有动因（motivated）的？——Givón 反对索绪尔式任意性学说的绝对化：语法的形式-功能映射大体同构，同构性有认知（解码经济性）与生物编码层面的基础。
  2. 语法中大量的一词多义与同义异形是无序的例外，还是系统性的、可预测的产物？——Givón：二者是语法化与语音磨损的系统副产品，其类型与分布可预测。
  3. 语言如何在持续变化中维持可解码性？——「同构化」压力（更新、竞争、分层）与「去同构化」力量（语法化、磨损）的动态平衡。
  4. （把字句视角）处置式史的「多标记竞争」与「把」的多功能性如何理论化？——同一功能域的多形式竞争 = 同义异形（allolexy）；同一形式的链上多义 = 一词多义（polysemy）；两者都源于语法化链，靠竞争与更新回归同构。

关键论证

（据知识精读重建；章节结构与页码待核） 1. 同构性命题（isomorphism thesis）：语法代码的默认状态是「一形一义」。编码不是任意的——形式-功能映射受认知与交际压力驱动（一一对应使处理/解码成本最小化），与生物编码系统（如遗传密码）同理——题名中「cognitive and biological considerations」即指此。 2. 错配的两类（对 bi-uniqueness 的系统性偏离）： - 一词多义/同音异义（polysemy / homonymy）：一形多功能（one form, many functions）——英语 -s（复数/领属/一致）；汉语「把」（持拿动词/处置标记/被动标记/受益标记）。 - 同义异形/异形态（allolexy / allomorphy）：一功能多形式（one function, many forms）——英语过去时（-ed/-t/元音交替/零形式）；汉语处置域（以/将/把/持/取/捉）。 3. 错配的历时来源 = 语法化：① 链的中间态必然多义——词汇项沿 语法化链 虚化时新义叠加旧义（旧义滞留），链越长多义越甚（「了」：了结/动结补语/了₁/了₂ 同形）；② 一源多流（polygrammaticalization）——同一源头在不同句法环境分叉成不同功能（「着」→ 持续貌/处所介词），制造同形异义；③ 多源平行语法化——同一功能域由不同词汇来源各自成链（处置标记：将/把/持/取），制造同义异形；④ 语音磨损（语音弱化）——不同来源磨损为同音形式（结构助词 的/地/得 合流 de），制造同音异义。语法化因此是同构性违反的主要生成器。 4. 同构性的恢复机制：更新（renewal）——磨损过度、多义负荷过重的形式被新语法化成分替换（「却→了」：却 衰亡、了 补入同一功能位），替换恢复功能域内的一形一义；竞争（competition）——同义异形经长期竞争后收敛（「将→把」：将 退居南方方言/书面语）；分层（layering）——新旧形式长期并存维持同义异形（Hopper & Traugott 2003 亦述此原则）。由此语法化呈循环（grammaticalization cycle：词汇化 → 磨损 → 更新），循环性本身解释了语法化单向性的经验方向（磨损不可逆）。 5. 动态平衡论：共时语法 = 「同构化压力（编码）」与「去同构化力量（变化）」的平衡态；错配不是噪声而是「进行中的语法化」的化石——共时错配的类型与分布可用来重建历时语法化路径（方法论文含义：同义异形 = 多链竞争的证据；一词多义 = 单链中间态的证据）。

与我的研究方向的关系

  • 新建概念：同构性（isomorphism）（新卡，2026-08-16）——形式-功能一一对应的编码压力；两类违反；语法化为违反之源、renewal/竞争为恢复之力
  • 更新概念：
  • 语法化链：链 = 同构性违反的生成器（中间态多义、一源多流）；链的更替（却→了）= renewal 恢复同构
  • 语音弱化：磨损 = 同音异义的来源之一 + 触发 renewal 的动因（补充江蓝生 2001 的「标尺」视角：弱化不仅是语法化程度的度量，还是语法化循环的推动力）
  • 处置式：处置功能域的多标记竞争（以/将/把/持）= 同义异形；「把」的多义（处置/被动/受益）= 一词多义；处置/被动同形句 = 同音异义的系统案例
  • 语法化单向性：renewal 循环为方向性提供功能派解释（磨损不可逆 → 循环 → 方向）
  • 与生成派理论的接口：同义异形（allolexy）≈ 竞争语法（Kroch 1989）的功能派对应物——「功能竞争」与「语法竞争」是同一现象的两个描述层；renewal ≈ 语法化的生成句法解释（Roberts & Roussou 2003）中「新词汇项重新语法化进入功能位」的功能派表述
  • 可接入的想法：处置式与被动式演变的参数互动（被/把同形与分化 = 同音异义的消解；武汉方言「把」兼处置/被动待读）、汉语语法化产物与句法分析性——功能语类显现方式的历时证据（分析性 = 汉语式 renewal 的形态句法后果：新功能词而非词缀）

阅读后该想的问题

  1. 同义异形（allolexy）与竞争语法（Kroch 的语法竞争 + 恒定比率假设）是同一现象的两个描述层还是两种机制：功能派的「功能域竞争」能否给出与「竞争语法」兼容的定量预测（替换速率、并存阶段的比率）？
  2. 把字句史的「将→把」更替与「却→了」更替在 Givón 框架下都是 renewal，但前者是同义异形收敛（功能不变、形式换），后者是同功能位换人（功能位不变、成员换）——两类更替的动因（磨损程度、多义负荷、使用频率）是否相同？能否用断代语料测量「多义负荷」？
  3. 「把」的多义链（持拿→处置→被动→受益）按 Givón 预测应朝「磨损→更新」方向演化，但现代汉语「把」仍是独立轻读词、未进一步磨损——句法分析性是否构成对「语法化循环」终点预测的系统性偏离（循环在汉语停在「分析性」段）？
