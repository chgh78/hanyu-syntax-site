汉语历时句法学知识库

以「历时生成句法学」（Diachronic Generative Syntax）为理论主轴的个人研究知识库， 覆盖整个汉语史（上古、中古、近代、现代）。

四层结构（Zettelkasten 卡片盒笔记法）

目录 内容 入口
papers/ 论文精读笔记——这篇论文说了啥 论文索引
concepts/ 概念笔记——原子概念，密集互链 概念索引
ideas/ 研究想法——概念交叉的选题 研究想法索引
surveys/ 综述——把一类东西串起来 综述索引
daily/ 每日精读记录与反馈 daily/ 按日期
inbox/ 待读文献入口（PDF/链接） —

使用方式

每日精读（自动）

每天 07:00 由常驻调度器触发 scripts/daily_run.sh（替代 launchd——macOS TCC 拦截 launchd 访问 ~/Documents）： - 启动：双击「启动每日精读调度.command」（或 nohup /opt/anaconda3/bin/python3 scripts/daily_scheduler.py >> daily/scheduler.log 2>&1 &） - 说明：开机后需手动启动一次（调度器由用户会话启动，才能获得 ~/Documents 访问权限）；错过 07:00-08:00 窗口会自动补跑 - 停止：pkill -f daily_scheduler.py - 手动：随时可跑 scripts/daily_run.sh 1. 从 inbox/（PDF）或「待选队列」中选文；队列空时自动从 Zotero 相关 collection（23 个）拉取新文献补队，经 dedup.py 三级去重（DOI→标题相似度→作者+年份，research-hub v1.0.6） 2. 精读 → 生成 papers/ 笔记（或更新已有笔记） 3. 提炼/更新概念卡片与链接 4. 生成当日 daily/YYYY-MM-DD.md（含三个要点 + 思考问题） 5. 重建静态网站

你可以在当日 daily 笔记的「你的反馈」处留言，下次运行会回写进知识库。

手动触发

~/Documents/汉语历时句法学知识库/scripts/daily_run.sh        # 跑一次完整流程
~/Documents/汉语历时句法学知识库/scripts/manual_read.sh "某文献"  # 指定精读某文献
~/Documents/汉语历时句法学知识库/scripts/build_site.sh       # 只重建网站

静态网站（本地预览）

运行 scripts/build_site.py 后，用浏览器打开 site/index.html 即可查看 带链接与反链的知识库网页版（无需服务器；以后有云服务器可直接上传 site/）。

理论基础速览

  • 参数重设（Lightfoot 1979）：语法变化发生在代际习得
  • 竞争语法（Kroch 1989）：新旧语法并存竞争，恒定比率假设
  • 语法化的最简分析（Roberts & Roussou 2003）：词汇项 → 功能语类
  • 句法分析性（黄正德 2015）：汉语功能语类以独立词拼出
  • 韵律句法学（冯胜利 1996）：韵律驱动语序演变
  • 详见 历时生成句法学理论综述
